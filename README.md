One line in the voice of a hardware wallet refusing to sign a transaction at 3 AM: it only gets woken at that hour to sign things its owner will regret by breakfast, and it has read the history to prove it.

## Run it

```sh
python3 main.py
```

The program writes the excuse to `/output/entry.txt` and makes no network calls.
